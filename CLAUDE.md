@AGENTS.md

The working rules for this repository live in [`AGENTS.md`](AGENTS.md) so that
every coding agent follows the same ones, not just Claude Code. Read that file
and follow it.

Project-specific notes:

- Environment is managed by **uv**. Never `pip install` into a system or global
  interpreter.
- This repository is **public** on GitHub. Treat everything committed to it as
  published, including commit metadata.
