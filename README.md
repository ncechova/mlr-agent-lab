# mlr-agent-lab

A small scratch space for experimenting with coding agents and Python tooling.

## Status

Currently a starting point — the folder holds a single placeholder script.
Expect the layout to change as experiments get added.

## Getting started

The project uses [uv](https://docs.astral.sh/uv/) for environment and dependency
management.

```bash
uv venv
uv run python hello.py
```
